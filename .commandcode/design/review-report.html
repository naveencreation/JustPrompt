Earned accent color

Thoughtful card depth

Image z-10 → overlay z-20 → like pill z-30. Each layer has its own animation timing. The depth system is intentional.

Proper rollback patterns

Like: optimistic + localStorage + server fallback with undo. Not a confirm dialog. The right interaction choice.

Mobile-aware hover gating

Card tilt only on pointer:fine. Mobile tap opens lightbox directly. No hover-only affordances.

Focus management

Lightbox saves and restores previous focus. Skip link present. Focus-visible rings on interactive cards.
